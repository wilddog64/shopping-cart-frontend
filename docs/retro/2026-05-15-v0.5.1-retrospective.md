# Retrospective — shopping-cart-frontend v0.5.1

**Date:** 2026-05-15  
**Branch:** `shopping-cart-frontend-v0.5.1`  
**Merge SHA:** `19e4711`  
**PR:** #15

## Summary

Fixed Keycloak SSO wiring in the shopping-cart-frontend after an accidental commit to `main` and a fast-follow revert. The fix re-applies the VITE build arg and nginx CSP configuration that were needed to complete the multi-repo SSO integration.

## Changes

1. **`.github/workflows/ci.yml`** — Added `VITE_KEYCLOAK_URL=http://keycloak.shopping-cart.local` as a build arg to the reusable CI workflow; updated the workflow SHA pin to `8c581840` (shopping-cart-infra commit that added `build-args` support)
2. **`nginx.conf`** — Replaced stale Istio DNS reference (`http://keycloak.identity.svc.cluster.local:8080`) with canonical browser hostname (`http://keycloak.shopping-cart.local`) in CSP `connect-src`
3. **`k8s/deployment.yaml`** — Added `nginx-cache` emptyDir at `/var/cache/nginx` for nginx UID 101 to create cache subdirectories; removed the erroneous `conf.d` emptyDir that was hiding the packaged nginx config

## Issues Encountered

- **Accidental remote push:** The initial fix commit (`6120783`) was committed and pushed to `main` without going through the PR/review gate, circumventing the intended workflow
- **Copilot review catch:** Copilot flagged that the PR diff showed only docs changes (CHANGELOG, issue-doc) but not the functional changes; investigation revealed a merge-base mismatch where the PR was created against `HEAD~4`, causing the functional commits to fall outside the PR diff view
- **Revert and re-apply:** The erroneous `main` commit was reverted (`2872a4c`), and the fix was re-applied via a fresh PR branch merge (`shopping-cart-frontend-v0.5.1`) to restore the clean PR chain

## Participants

- Claude — scoped SSO integration, wrote issue-doc for accidental push, coordinated revert
- Codex — applied fixes to CI and nginx config
- Copilot — caught the diff/merge-base mismatch and flagged the CI configuration SHA

## Lessons Learned

1. The reusable workflow CI pattern requires careful SHA pinning; shopping-cart-infra must announce breaking changes to the `build-args` interface in release notes
2. Accidental remote pushes bypass PR review gates — coordinate with team on how to prevent (e.g., enforce `--no-publish` on feature branches)
3. Copilot's diff-view checking caught a subtle merge-base misalignment that would have been hard to debug after the fact
